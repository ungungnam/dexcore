Everything is inherited: the 64-frame sequences and the fixed take-level split (TACO <<n_taco_train_seq>> / <<n_taco_val_seq>> / <<n_taco_test_seq>> sequences from <<n_taco_train_takes>> / <<n_taco_val_takes>> / <<n_taco_test_takes>> takes; ARCTIC <<n_arctic_train_seq>> / <<n_arctic_val_seq>> / <<n_arctic_test_seq>> from <<n_arctic_train_takes>> / <<n_arctic_val_takes>> / <<n_arctic_test_takes>>), the canonical 512-point contact maps, the static descriptor G (1032-D), the per-frame object-trajectory window τ_local,t (nine object states at t − 8 … t + 8, stride 2; <<dtau_taco>> / <<dtau_arctic>> values), and the frozen Stage-1 A3 encoder (checkpoint md5 `<<md5_taco>>` / `<<md5_arctic>>`, the same file Stage 2 used as its teacher).

`zt_cache.py` writes one cache per dataset with, for every frame of the train / validation / test sequences, the contact map C_t, the latent z_t = E_z(C_t, G_t), G and τ_t (plus the Stage-1 teacher descriptors — exact R2 and wrench — which are used only in the temporal-geometry analysis). The latents are the ones Stage 2 was trained against; re-encoding every frame with the frozen encoder reproduces them up to bf16 rounding (largest deviation <<fresh_taco:.4f>> / <<fresh_arctic:.4f>> train standard deviations). z is standardised per dimension with the mean and standard deviation of the **train** frames (raw per-dimension standard deviation <<zsd_lo_taco:.1f>>–<<zsd_hi_taco:.1f>> / <<zsd_lo_arctic:.1f>>–<<zsd_hi_arctic:.1f>>); all latent errors below are in these standardised units, in which the train-mean predictor has an RMSE of about 1. Stage 1 is not retrained and no representation is modified.
